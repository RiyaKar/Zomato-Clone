
# 🍽️ Zomato Clone – Food Ordering & Restaurant Discovery Website
Check out the live project here 👉 [Live Site](https://01zomato-clone.netlify.app/)


A frontend clone of **Zomato**, designed to replicate its food discovery and online food ordering experience. The website allows users to explore restaurants, browse food categories, view menus, and interact with the food ordering interface through a clean and user-friendly design.

## 💻 Setup Instructions

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd zomato-clone
```

### 3. Run the Project

Open the `index.html` file directly in your browser.

Alternatively, use the **Live Server** extension in VS Code for a better development experience.
